# 🚀 TaskFlow Pro

A Professional Full Stack Task Management Web Application built using MERN Stack.

## 📌 Features

* User Login & Signup
* Add New Tasks
* Edit Tasks
* Delete Tasks
* Mark Tasks as Completed
* Task Statistics Dashboard
* CSV Export Functionality
* Duplicate Task Prevention
* Toast Notifications
* Responsive Modern UI
* MongoDB Database Integration

---

## 🛠 Technologies Used

### Frontend

* React JS
* Axios
* React Toastify
* React CSV
* CSS3

### Backend

* Node JS
* Express JS

### Database

* MongoDB Atlas / MongoDB Compass

## ⚙️ Installation

### Backend

```bash
cd backend

npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
